### About

I'm a Computer Science student at Instituto Mauá de Tecnologia and a full-stack developer based in São Paulo.

I build web applications with TypeScript, React and Node.js. I write interfaces and APIs, model PostgreSQL databases, implement authentication and deploy applications.

I also work on product decisions and technical planning. Right now, I'm studying how to evaluate and improve the reliability of AI agents.
